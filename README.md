## 📋 Overview

**CliniScan** is an end-to-end deep learning system for detecting and classifying lung abnormalities in chest X-rays using the **VinDr-CXR** dataset (via Kaggle). It combines:

| Component | Model | Purpose |
|-----------|-------|---------|
| **Classification** | ResNet50 + custom head | Predict which of 14 lung conditions is present |
| **Detection** | YOLOv11s | Localise abnormalities with bounding boxes |
| **Interpretability** | Grad-CAM | Highlight the image regions driving predictions |

### Supported Conditions (14 classes)

| ID | Condition | ID | Condition |
|:--:|-----------|:--:|-----------|
| 0 | Aortic enlargement | 7 | Lung Opacity |
| 1 | Atelectasis | 8 | Nodule/Mass |
| 2 | Calcification | 9 | Other lesion |
| 3 | Cardiomegaly | 10 | Pleural effusion |
| 4 | Consolidation | 11 | Pleural thickening |
| 5 | ILD | 12 | Pneumothorax |
| 6 | Infiltration | 13 | Pulmonary fibrosis |

## 🏗 Architecture

```
┌──────────────────────────────────────────────────────────────┐
│                     Chest X-ray Input                        │
└────────────┬──────────────────────┬──────────────────────────┘
             │                      │
    ┌────────▼────────┐    ┌───────▼────────┐
    │  ResNet50 + FC  │    │   YOLOv11s     │
    │  Classifier     │    │   Detector     │
    └───┬─────────┬───┘    └───────┬────────┘
        │         │                │
   ┌────▼──┐  ┌──▼──────┐   ┌────▼──────┐
   │ Top-5 │  │ Grad-CAM│   │ Bounding  │
   │ Probs │  │ Heatmap │   │ Boxes     │
   └───────┘  └─────────┘   └───────────┘
```

### Classification Pipeline (ResNet50)

- **Backbone**: ResNet50 pretrained on ImageNet
- **Custom Head**: `Dropout(0.4) → Linear(2048, 256) → ReLU → Dropout(0.2) → Linear(256, 14)`
- **Training Strategy** (Milestone 3):
  - **Phase 1** (5 epochs): Frozen backbone, train head only (LR = 1e-3)
  - **Phase 2** (10 epochs): Full fine-tuning (AdamW, LR = 1e-5, cosine annealing)
- **Augmentations**: CLAHE, horizontal flip, shift-scale-rotate, brightness/contrast, Gaussian noise, coarse dropout
- **Input**: 224×224 normalised RGB
- **Loss**: CrossEntropy with label smoothing (0.1)

### Detection Pipeline (YOLOv11s)

- **Model**: YOLOv11s (Ultralytics)
- **Training** (Milestone 3): 40 epochs, imgsz=640, batch=16
- **Hyperparameters**: lr0=0.005, cosine LR, mosaic=1.0, mixup=0.15, patience=10
- **Output**: Bounding boxes with class labels and confidence scores

## 🚀 Quick Start

### 1. Clone & Install

```bash
# Clone the repository
git clone <your-repo-url>
cd cliniscan

# Install dependencies
pip install -r requirements.txt
```

### 2. Place Model Weights

Download the trained model weights and place them in a `models/` directory:

```
cliniscan/
├── models/
│   ├── cliniscan_best_cls_m3.pth   ← ResNet50 classification checkpoint
│   └── best.pt                      ← YOLOv11s detection checkpoint
├── cliniscan_app.py
├── requirements.txt
└── README.md
```

Model weights are generated by running the Milestone 2-3 training notebooks on Kaggle.

### 3. Launch the Demo

```bash
python cliniscan_app.py
```

Open `http://localhost:7860` in your browser. Upload a chest X-ray to see:
- **Top-5 predictions** with confidence scores
- **Grad-CAM heatmap** showing model attention
- **YOLO detections** with bounding boxes

## 📓 Milestone Notebooks

| Milestone | Notebook | Description |
|:---------:|----------|-------------|
| M2 | `cliniscan-milestone2 & 3.ipynb` | Data loading, YOLO format conversion, initial ResNet50 & YOLOv11s training |

All notebooks are designed to run on **Kaggle** with the VinDr-CXR dataset.
